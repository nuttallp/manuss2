# Manuss2

Repository scaffold containing a sample GitHub Actions workflow. No application implementation is currently included.

[![Repository security](https://github.com/nuttallp/manuss2/actions/workflows/repository-security.yml/badge.svg)](https://github.com/nuttallp/manuss2/actions/workflows/repository-security.yml)

## Maintenance and diagnostics

[Actions](https://github.com/nuttallp/manuss2/actions) shows repository checks; the [Security tab](https://github.com/nuttallp/manuss2/security) shows available alerts. A workflow badge reports checks, not application uptime. Include the commit, error code, and sanitized reproduction when reporting a failure.

See [CONTRIBUTING.md](CONTRIBUTING.md) for changes and [SECURITY.md](SECURITY.md) for private vulnerability reports.
